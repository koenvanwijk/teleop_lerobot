🌐 Open Web Interface
📱 Hoe te gebruiken:
  1. Zorg dat Bluetooth aan staat op je apparaat
  2. Start de Bluetooth service op de robot
  3. Klik op "Scan voor LeRobot"
  4. Selecteer het LeRobot-IP apparaat
  5. Het IP-adres wordt automatisch getoond
⚠️ Android tip: Als scannen niet werkt, gebruik eerst je Bluetooth instellingen om "LeRobot-IP-x.x.x.x" te vinden, noteer het IP-adres uit de naam.
⚠️ Let op: Web Bluetooth wordt alleen ondersteund in Chrome, Edge en Opera browsers.
🔒 HTTPS vereist: Web Bluetooth werkt alleen via HTTPS. Probeer via http:// ipv https:// of gebruik Android Bluetooth instellingen.
